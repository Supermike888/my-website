# Правила разработки сайта

## Тесты

Тесты сайта предназначены для самопроверки и самообразования. По умолчанию:

- Не запрашивать имя, фамилию, ФИО или другие данные кандидата.
- Не вводить оценки, проходные пороги и статусы «пройден / не пройден».
- Показывать число правильных ответов, процент и время; сохранять привычные механизмы результатов, повторного прохождения и PDF.
- Ориентироваться на текущее оформление тестов сайта. Старые требования из чатов о проверке кандидатов не переносить в новые тесты.

Иное поведение добавлять только по явной просьбе пользователя.

Отправку изменений в GitHub и публикацию через Coolify согласовывать отдельно.
